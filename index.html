01 — Objectives
  • Continuously sense physiological stress markers using multi-modal biometric sensors
  • Correlate GSR, heart rate, and ambient conditions to compute a composite stress index
  • Enable real-time wireless data transmission via ESP32 Wi-Fi / Bluetooth
  • Provide visual dashboard with threshold-based alerts for stress & anomaly detection
  • Extend use case to polygraph-style deception detection by analyzing autonomic response patterns
  • Log time-series sensor data for offline analysis and pattern recognition
